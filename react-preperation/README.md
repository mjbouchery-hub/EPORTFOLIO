# React Preparation

A coursework project built while completing Frontend Simplified’s Final Preparation lessons.

## Features

- Fetches and displays user cards from JSONPlaceholder.
- Opens each user’s posts through a dynamic route.
- Searches posts by user ID using the search button or Enter key.
- Displays loading skeletons while fetching posts.
- Provides back navigation and request error messages.

## Built With

- React
- React Router
- Axios
- CSS
- Create React App

## Run Locally

From the project folder:

npm install
npm start

## Data Source

Uses JSONPlaceholder’s sample users and posts:
https://jsonplaceholder.typicode.com/
